# Lawson Fuji (ローソン 富士山)

A cozy first-person browser game set in a small Japanese town at the foot of
Mt. Fuji. Walk into the famous Lawson, browse the shelves, heat a bento,
chat with the clerk, pay, and step back out under the mountain.

## Run it
npm install
npm run dev

Desktop browsers only.

## Controls
| Action | Input |
| --- | --- |
| Move | W A S D |
| Run (outdoors) | Shift |
| Look | Mouse (pointer lock; Esc to release) |
| Interact | E |
| Basket | Tab |
| Famous view (hero camera for the current time of day) | F |
| Photo mode | P |
| Ambience / music | M |
| Pause and settings | Esc |

## Audio
Sound files are not included in this repository and are not covered by the
MIT licence. See SPEC.md section 9 for the list and where to download each
one into assets/audio/. The game falls back to generated sounds when a
file is missing.
